# Impeccable Design Principles

Use this skill when redesigning UI to remove AI-generated patterns and create intentional, polished design.

## Anti-Patterns to Remove

1. **Overused fonts** - Avoid Inter, Arial, system defaults for display text
2. **Gray text on colored backgrounds** - Use proper contrast
3. **Pure black/white** - Always tint blacks and whites
4. **Nested cards** - Cards within cards create visual noise
5. **Bounce/elastic easing** - Feels dated and unprofessional
6. **Purple gradients** - Overused in AI-generated UI
7. **Glassmorphism** - Trendy but often unnecessary
8. **Decorative calibration marks** - Don't add marks that don't align with content
9. **Wide rounded cards** - Keep radius tight and intentional
10. **Generic AI-tool glow** - Avoid neon effects

## Design Rules

### Colors
- Use warm dark surfaces (not pure black)
- Primary accent: strategic, not everywhere
- Secondary accent: for state and contrast only
- Text: high contrast on dark, muted on light

### Typography
- Display: clean, geometric sans-serif
- Body: readable, good line-height (1.6-1.8)
- Labels: uppercase, tracked, short

### Layout
- Tight border radius (2-8px max)
- Minimal shadows (prefer borders)
- Generous spacing between sections
- No nested cards or unnecessary containers

### Components
- Buttons: clean, minimal, purposeful
- Forms: simple inputs with subtle borders
- Cards: flat, bordered, compact
- Sections: clear hierarchy with breathing room

## Application

When redesigning:
1. Remove all AI slop patterns
2. Apply tight, intentional styling
3. Use color sparingly for emphasis
4. Keep layout clean and functional
5. Focus on content hierarchy
